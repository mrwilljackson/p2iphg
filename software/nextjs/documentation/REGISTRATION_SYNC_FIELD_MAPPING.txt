=== SYNC LOGIC SUMMARY ===

1. Query all registrations from Neon where sync_status = 'pending' (or all, if first sync)
2. For each registration:
   a. Look up event's airtable_record_id from events table
   b. Look up organisation's airtable_record_id from organisations table (if org linked)
   c. Build Airtable fields object with mapped field names
   d. Create record in Airtable via API
   e. On success: store returned Airtable record ID in Neon, set sync_status = 'synced'
   f. On failure: set sync_status = 'failed', log error
3. Return summary of created/failed records


=== AIRTABLE API NOTES ===

- Airtable batch creates support up to 10 records per request
- Checkboxes: send true for checked, omit field entirely for unchecked (do NOT send false)
- Linked records: send as array of Airtable Record IDs, e.g. ["recABC123"]
- Rate limit: 5 requests per second per base

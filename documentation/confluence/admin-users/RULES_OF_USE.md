# Guidelines of Use for Power2Inspire Event CRM App

## 1. Introduction
There are some basic rules of use for the Power2Inspire Event CRM App. Please read them carefully before using the app. These are intended for the person running the event registration on the day of the event. 

## 2. Basic Guidelines
All attendee's who will be playing games should register as a **Participant**. 

All teachers/coordinators/parents/community group leaders should register as **Group leaders**.

Anyone helping who isn't participating in the games should choose '**Helper**' registration.

## 3. Guidelines for each type of attendee
Registration only takes around couple of1 clicks/taps to complete, but is essential for P2I monitoring and fundraising! Please encourage everyone to register.


### 3.1 Group Teachers, Coordinators, Parents and Leaders
The group leaders will already have been added to the system by P2I along with the numbers of participants they expect to bring. If the number of participants is different on the day, that's not a problem, as we ask them to provide the correct number on the day. If a different representative is there on the day, they should be asked to add their name and email against their organisation so that we have contact details for the day in case of emergencies, etc.

### 3.2 Partner/Supporter Organisations
Typically P2I has made contact with a person from a partner/supporter organisation and they have arranged to bring colleagues to participate in the event. This person should still register as a participant. Our system will match their email and record them in the registrations as a 'group leader' and reference the number of expected participants.

### 3.3 Helpers
The helpers simply need to register as helpers. They choose their name from the prepared list in the system. If their name is not on the list, they should contact P2I to be added. No need to enter any details as we already have them in the system. This simply helps us keep track of how many, and who is helping on the day, and over the long term. The Event coordinator could easily do this on their behalf on the day.

## 4. What if people turn up who have not pre-registered?
No problem!

### 4.1 New Participants
You can add them as a participant using the option 'Individual' in the organisation pulldown.

### 4.2 New Groups 
You can add a new group within the event 'admin' pages, then people in this group can either be added as a total number or as individuals.

### 4.3 New Helper: 
Simply add the person as a helper in the event admin pages and their name will appear in the list of helpers for registration.

## Event Admin Pages
This is a set of pages that you can use to see how many people have registered, who they are, and their organisations and groups. The idea being that this information makes it easy to liaise with group leaders to ensure all their attendee's register with the system.

### Log in as 'Event Admin'
At the foot of the registration page there is a link with the text 'Admin' - click this to access the Admin log in panel. Enter your PIN code as advised by P2I coordinator, then click the green button to log in. 

### Event Dashboard
The Event Dashboard gives a high level view of the event. It shows the number of participants, groups and helpers registered. It also shows the number of places expected for each group. The panel of 'Registered Participants' shows totals for expected and registered participants. Each row has a little arrow on the right - click this to see the names of all those registered participants.

If the row is highlighted yellow that means there are fewer than expected registered participants. Your challenge is to check with the 'group leader' to help identify those attendees who have not yet registered!

The 'Groups' panel shows the number of groups registered and the number of places expected for each group. 
 
The 'Helpers' panel shows the names of helpers who are expected and registered.
